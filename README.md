# 🩸 LifeSaver - Blood Donation Portal

## How to run this project:
1. Open terminal and run `npm install` to get the required packages.
2. Open Oracle SQL Plus and run the code inside `database.sql` to create the database and test users.
3. Open `server.js` and change the database password to your own Oracle password.
4. Run `node server.js`.
5. Open `index.html` in your browser!
